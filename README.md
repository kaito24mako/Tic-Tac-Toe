#  Tic-Tac-Toe
A Tic Tac Toe game!
It does NOT feature the factory functions and IIFEs that The Odin Project asked to be included.

### ⚙️ Features
- A 2-player Tic Tac Toe game, played on a webpage
- Constructors, functions, and forms to enable custom player names
- A score tracker for endless play with your opponent!
- Arrays that keep track of win conditions, along with DOM styling to highlight the winning combination in each round
- Responsive styling that allow for play for mobile, laptops, and larger monitors!
